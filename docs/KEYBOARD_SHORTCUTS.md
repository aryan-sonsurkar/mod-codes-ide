# MODCODES Keyboard Shortcuts

All `Ctrl` shortcuts also work with `Cmd` on macOS.

## Global Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+Shift+P` | Toggle Command Palette |
| `Ctrl+P` | Go to File |
| `Ctrl+G` | Go to Line |
| `Ctrl+Shift+O` | Go to Symbol in File |
| `Ctrl+T` | Go to Symbol in Workspace |
| `Ctrl+Tab` | Switch to Recent Tab |
| `Ctrl+S` | Save Active File |
| `Ctrl+W` | Close Active Tab |
| `Ctrl+B` | Toggle Sidebar (Explorer / Search) |
| `Ctrl+F` | Find in File (Monaco editor) |
| `Ctrl+Alt+Left` | Switch to Left Tab |
| `Ctrl+Alt+Right` | Switch to Right Tab |
| `Escape` | Cancel / Close current dialog or modal |

## Tab Bar

| Key | Action |
|-----|--------|
| `Arrow Left` | Switch to tab on the left |
| `Arrow Right` | Switch to tab on the right |
| `Home` | Switch to first tab |
| `End` | Switch to last tab |
| Middle Mouse Click | Close the clicked tab |

## File Explorer

| Key | Action |
|-----|--------|
| `Arrow Down` | Move to next item |
| `Arrow Up` | Move to previous item |
| `Arrow Right` | Expand directory (or move to next item if file) |
| `Arrow Left` | Collapse directory (or move to parent if file) |
| `Enter` / `Space` | Open file or toggle directory |

## Terminal

| Key | Action |
|-----|--------|
| `Enter` | Execute command |
| `Arrow Up` | Previous command in history |
| `Arrow Down` | Next command in history |

## AI Chat

| Key | Action |
|-----|--------|
| `Enter` | Send message |
| `Shift+Enter` | Insert newline in message |

## Dialog Navigation

All dialogs (Command Palette, Go to File, Go to Symbol) support:

| Key | Action |
|-----|--------|
| `Arrow Up` / `Arrow Down` | Navigate list |
| `Enter` | Select / Confirm |
| `Escape` | Close dialog |
